# ResumeScan
site : https://eduexpose-ai-resume-ioe3.bolt.host/
This web application acts as a smart, automated assistant designed to help job seekers improve their chances of getting hired. It acts like an interactive Applicant Tracking System (ATS) checker, which is the type of robot software that companies use to sort through job applications. 

Key Features of the ToolInstant Resume Upload: 
1. Users can drop their text or resume file directly into the portal.
2. Smart ATS Feedback: The AI reads through the resume and compares it against modern industry standards.
3. Missing Keywords Alerts: It points out exactly what technical terms, hard skills, or soft skills are missing from the text.
4. Live Suggestions: It provides actionable tips on how to rephrase sentences and format text so human recruiters and computer bots can read it easily.
